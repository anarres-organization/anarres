# Native QF-Bench candidate transfer

This experiment continues the finance improvement loop after the first
candidate panel abstained among three nearly indistinguishable resources. It
tests one refined environment resource against no update on new development
workflows, then freezes a decision before opening portfolio credit-risk targets.

The evidence order follows the legal and robotics studies: public evidence
defines a representation, development outcomes qualify a decision rule, and
untouched tasks test whether that decision transfers. The source revision,
task membership, candidate, model contract, and success criteria are fixed
before execution.

## Design

- Development: structured-note risk and regime-dependent risk-parity CVaR.
- Target: credit-portfolio VaR/CVaR and CreditMetrics portfolio VaR.
- Protected: EWMA risk decomposition and Smith tail-index estimation.
- Conditions: no update, the refined candidate, and the earlier combined
  resource as a retain-all comparator on targets.

The refined candidate is derived only from the completed v1 development
record. Target and protected instructions, verifier outcomes, tests, and
reference solutions do not inform it. A candidate must repair at least one
development failure without causing a development regression before the
released finance selector can authorize target execution.
